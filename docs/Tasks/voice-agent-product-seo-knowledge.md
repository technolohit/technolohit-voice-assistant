## 1. Product definition

The **TechnoloHit Voice Agent** is a KI-gestützter Telefonassistent for companies.

It can help companies:
- take incoming calls
- understand caller intent
- ask relevant follow-up questions
- collect contact details
- capture lead information
- summarize the conversation
- prepare next steps
- notify the team
- hand off to humans or connected systems

The Voice Agent is not a simple voicemail, not a generic speech bot, and not a promise of fully automated sales.

Core positioning:

```text
Der Voice Agent hilft Unternehmen, Anrufe nicht nur anzunehmen, sondern daraus strukturierte Anfragen, Leads und nächste Schritte zu machen.
```

## 7. Practical examples

### Example 1: Local business

A local company has a website and receives calls, but the team is busy. The Voice Agent can ask for name, phone number, service needed, location, urgency and preferred callback time. Then it can summarize the call and send the lead to the team.

### Example 2: Smart Website + Voice Agent

A Smart Website improves visibility and inquiry paths. Some visitors submit forms; others call. The Voice Agent can capture the phone inquiries with similar structure and prepare next steps.

### Example 3: Botinteg + Voice Agent

Botinteg handles website chat and written inquiries. The Voice Agent handles telephone inquiries. Together they create clearer inbound communication across chat, forms and calls.

### Example 4: Existing website with poor follow-up

A company already has a website, but many leads come through phone calls. The Voice Agent can turn calls into structured lead records and notify the team.

## 14. FAQ

### Was ist ein Voice Agent?

Ein Voice Agent ist ein KI-gestützter Telefonassistent, der Anrufe entgegennehmen, Anliegen verstehen, Informationen erfassen und nächste Schritte vorbereiten kann.

### Kann der Voice Agent Leads erfassen?

Ja. Der Voice Agent kann Kontaktdaten, Bedarf, Thema, Dringlichkeit und weitere relevante Informationen erfassen und als Lead an Ihr Team oder ein angebundenes System weitergeben.

### Kann der Voice Agent mit meiner Website oder Datenbank verbunden werden?

Je nach technischer Umgebung kann der Voice Agent mit Website-Formularen, Datenbanken, CRM-Systemen oder internen Workflows verbunden werden.

### Ersetzt der Voice Agent mein Team?

Nein. Der Voice Agent ist dafür gedacht, Teams zu unterstützen. Er kann Anfragen vorbereiten, Informationen erfassen und Übergaben strukturieren, aber menschliche Entscheidungen bleiben wichtig.

### Für welche Unternehmen eignet sich der Voice Agent?

Der Voice Agent eignet sich für Unternehmen, die regelmäßig Anrufe, Kundenanfragen oder wiederkehrende Fragen erhalten, zum Beispiel Dienstleister, lokale Unternehmen, Praxen, Agenturen, Immobilienmakler oder kleine Teams.

### Kann der Voice Agent mehrere Sprachen unterstützen?

Mehrsprachige Kommunikation kann je nach Setup und Anforderungen umgesetzt werden. Sprache, Tonalität und Antwortlogik sollten an Kundenstamm, Marke und Prozesse angepasst werden.

### Wie läuft die Einrichtung ab?

Zunächst wird der Anwendungsfall geklärt: Welche Anrufe kommen rein, welche Informationen sollen erfasst werden, welche Systeme sollen benachrichtigt oder angebunden werden und wann soll eine Übergabe an Menschen erfolgen.

### Ist der Voice Agent DSGVO-orientiert umsetzbar?

Der Voice Agent kann DSGVO-orientiert geplant werden, etwa mit klaren Datenflüssen, abgestimmten Speicherregeln und kontrollierten Integrationen. Eine rechtliche Prüfung ersetzt das nicht.
